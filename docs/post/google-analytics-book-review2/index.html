第一部：運作釐清篇

1. 秘訣：Email安裝GA追蹤 (插入相片 > 圖片網址)

在圖片網址處插入這段：
http://www.google-analytics.com/collect?v=1&tid=UA-XXXXXXXX-1&cid=max&t=event&ec=email&ea=open
解釋：
  1. v：GA版本號
  2. tid (tracking ID)： GA追蹤ID
  3. cid (customer ID)：收件者ID
  4. t：追蹤的形式
  5. ec (event category)：事件類別，我通常都是放此項動作的來源，例如 email
  6. ea (event action)：事件動作，我通常都是放此項動作的描述，例如 open

2. 秘訣：Gtag解讀和如何安裝第二組Gtag

Gtag解讀大致可分成三塊：

  1. 紅框部分(函式庫)：用來呼叫gtag.js函式庫內容，由於程式碼讀取具有順序性，因此紅框處的程式碼會放置於GATC的開頭。
  2. 藍框部分(數據暫存)：dataLayer是一個能夠存放網站行為數據的空間，透過dataLayer.push()函式能將數據提取至dataLayer暫存。
  3. 綠框部分(發送)：透過config指令，將存放於dataLayer的數據依照追蹤ID，傳回並呈現於報表。
如果要安裝第二組Gtag，直接在原本gtag下方加入即可
Google Analytics Tracking Code

3. 秘訣：網站讀取速度的組成

網站讀取速度主要可分成五個部分，從設定到讀取：
  1. 網頁重新導向時間(設定GPS導航)：就像是開啟導航系統一樣，要先確認是否能在導航系統中找到該目的地。
  2. 網域查找時間(查詢IP位置)：DNS查找時間，用來比對域名和IP位址的資料庫。
  3. 伺服器連線時間(連線)：找到IP後，伺服器連線。
  4. 伺服器回應時間(回應)：伺服器回應
  5. 文件讀取時間(讀取)：指當網頁的HTML文檔被觸發後所花費的載入時間。

第二部：名詞比較篇

1. 秘訣：維度vs指標

維度(綠色字體)：非量化數據 ex.年齡、性別
指標(藍色字體)：量化數據 ex.工作階段、跳出率

2. 秘訣：合併子目錄名稱及主機名稱

顯示到達網頁時，常常缺少網域名稱，可以在篩選器上調整，就可以在最後顯示時讓有完整的到達網址囉！
