想在 Claude 裡直接查詢 SHOPLINE 訂單、整理商品庫存，或請 AI 協助更新商品資料，可以透過 SHOPLINE MCP 連接商店。本篇從後台權限設定開始，帶你完成 Claude 授權，再用一筆訂單確認是否串接成功。

MCP（Model Context Protocol）是讓 AI 使用外部工具與資料的連接協定。在這個情境裡，你用文字交代需求，Claude 透過 SHOPLINE 提供的工具取得資料，再整理成回答；能操作哪些項目，取決於商店授權及 MCP 已開放的功能。SHOPLINE MCP 技術文件。

適用：Claude 網頁版與 Claude Desktop 的遠端連接器。本文於 2026 年 11 月 21 日核對官方文件；操作圖為依文件重繪的介面示意，欄位與選單以實際畫面為準。

開始前，先確認兩邊的使用條件

SHOPLINE 商店須具備 OpenAPI 功能，例如使用「全通路領航員」方案，或另行加購 OpenAPI。沒有這項功能時，請先向 SHOPLINE 確認方案資格。SHOPLINE 官方適用條件。

Claude 目前開放 Free、Pro、Max、Ultra、Team 與 Enterprise 使用遠端自訂連接器，免費版最多一個。Team 與 Enterprise 還有組織管理權限：一般成員需要由有權限的人先加入連接器，之後各自連接帳號。Claude 官方自訂連接器說明。

以下使用 Claude 介面完成設定。SHOPLINE 這套流程採用登入授權，不需要另外準備 API Key，也不用修改本機設定檔。

步驟一：開啟 SHOPLINE 管理員的 MCP 權限

先到 SHOPLINE 後台處理帳號權限：

  1. 進入「設定」→「管理員及安全設定」。
  2. 新增管理員，或編輯要拿來授權的管理員帳號。
  3. 切到 API Auth 分頁，啟用 MCP 權限。
  4. 勾選這次需要的資料與操作權限，按「更新」儲存。

店長帳號不能直接啟用 MCP。請另外建立管理員帳號供 Claude 授權使用。想在後台活動紀錄辨識 AI 操作，也可以為使用者建立各自的 AI 專用管理員。SHOPLINE 官方權限說明。

第一次可以從訂單、商品的查詢權限開始，等確認工作需求後，再開放需要的修改權限。

步驟二：在 Claude 新增 SHOPLINE 連接器

個人帳號：從 Customize 開始

開啟 Claude，依序進入 Customize → Connectors → Add → Add custom connector，新增自訂連接器。

Team／Enterprise：先由組織管理者加入

有新增權限的管理者從左下角帳號選單開啟 Organization settings → Connectors，按 Add 新增。依介面版本，入口可能顯示 Add custom connector，或是 Custom → Web。組織加入後，成員再回自己的 Customize → Connectors，找到 SHOPLINE 並連接。

個人與組織的入口依 Claude 官方說明整理。Team 通常由 Owner／Primary Owner 新增；Enterprise 另支援具備相關管理權限的自訂角色。

填入名稱與遠端網址

在新增視窗中，名稱可填 SHOPLINE，Remote MCP server URL 填入下方網址，再按 Continue：

https://shopline-open.shopline.io/mcp/on-demand

接著檢查驗證選項。依 SHOPLINE 對 Claude 的指定設定，Authentication 選 Sign in when needed；OAuth client 選 Register automatically（DCR），最後按 Add。若中途還有一頁設定檢查，確認後再按 Continue 繼續。SHOPLINE 官方 Claude 串接步驟。

步驟三：登入 SHOPLINE 並授權商店

連接器新增後，找到 SHOPLINE，按 Connect。跳轉到 SHOPLINE 登入頁時，使用剛才已開啟 MCP 權限的管理員帳號登入，選擇要連接的商店，再按 Authorize 完成授權。

授權後回到 Claude 的 Connectors 頁面，確認 SHOPLINE 已連接。SHOPLINE 密碼只在官方登入頁輸入即可。

新增連接器與商店授權是兩個步驟。只在列表看到 SHOPLINE 名稱時，還要確認已按 Connect 並完成授權。

步驟四：用一筆訂單確認連線

在 Claude 開啟新對話，從輸入框旁的 「＋」→ Connectors 確認本次對話已啟用 SHOPLINE。有工具執行確認視窗時，先檢查它準備執行的操作再允許。

找一筆你能在後台核對的訂單，將訂單編號代入這段指令：

請透過 SHOPLINE MCP 查詢訂單「填入你的訂單編號」。
列出訂單編號、訂單狀態、付款狀態與出貨狀態，
並註明目前查詢的商店名稱。
這次只讀取資料，不修改任何內容；找不到時請直接說明。

檢查 Claude 是否有呼叫 SHOPLINE 工具，並把回傳的商店、訂單與後台資料逐一對照。只回答一般性的訂單處理建議，還不足以確認商店資料已連通。

沒有合適的訂單，也可以改查一項已知商品的庫存。SHOPLINE 技術文件也以訂單與庫存查詢作為連線測試範例。

串接後，可以怎麼使用？

SHOPLINE MCP 的工具涵蓋訂單、商品、庫存、顧客與活動等資料，也提供部分新增及修改操作。實際可用範圍仍取決於開放進度與帳號權限，可參考 官方工具清單。下面是可以自行調整的指令範例，執行結果須以你的商店核對。

範例一：找出需要補貨的商品

請透過 SHOPLINE MCP 查詢目前上架商品，
找出庫存低於 10 的商品規格。
用表格列出商品名稱、規格、SKU 與庫存數量。
若有多個倉庫，請分開標示；只查詢，不調整庫存。
若無法取得完整清單，請說明本次涵蓋範圍。

把「庫存低」改成具體數字，並指定要看到的欄位，會更容易拿結果回後台核對。

範例二：整理一段期間的訂單

請透過 SHOPLINE MCP 查詢 2026/11/01 至 2026/11/07（含當日）
的訂單，以 Asia/Taipei 時區、訂單建立時間為準。
依付款狀態統計訂單筆數，取消的訂單另外列出。
請說明是否已讀取所有分頁，以及是否有資料無法取得。
只提供彙總，不列出顧客姓名、電話或地址。

日期與時區先寫清楚，再確認 Claude 取到的資料範圍。只拿到部分分頁時，請先補齊資料，再把結果當作完整期間的統計。

範例三：先預覽商品修改，再決定是否執行

請透過 SHOPLINE MCP 找出 SKU「填入你的 SKU」對應的商品。
我想把商品描述改成：「填入新的描述」。
先列出商品 ID、目前描述與預計修改內容，等待我確認。
這一輪不要寫入後台，也不要更動價格、庫存或上架狀態。

確認商品與修改內容後，再針對該商品下達執行指令，完成後回到後台檢查。描述修改、發券或發購物金，都適合把「先整理內容」與「正式執行」分開交代。

若要透過 MCP 建立優惠，SHOPLINE 目前指定支援的類型為滿額滿件優惠與免運費。建立後仍須進後台補齊付款、送貨方式，確認內容並手動上架。SHOPLINE 官方活動限制。

常見問題與排查方式

1. 找不到 Add custom connector，怎麼辦？

先確認目前進入的是個人帳號還是組織工作區。免費版如果已用掉一個自訂連接器，須處理現有連接器的名額；Team／Enterprise 成員則需請有新增權限的組織管理者加入。組織也可能限制 Connector 使用權限。

2. 已授權，Claude 卻說查不到資料？

先看本次對話是否已啟用 SHOPLINE，再檢查授權商店、管理員的 MCP 開關及所需資料權限。權限確認後仍無法使用，可依 SHOPLINE 建議：完整移除連接器、重新串接授權，再開新對話測試。

3. 勾選「授予全權」，就能使用所有後台功能嗎？

仍受 MCP 支援範圍限制。管理員勾選的權限與 MCP 已開放的能力，兩者都要符合；開放完整 OpenAPI 權限，也不代表每項後台操作都能交給 Claude。

4. 連接到錯的商店，如何切換？

可以請 Claude 切換商店，或解除連接後重新串接。切換時需要重新授權；完成後先查詢商店名稱與一筆已知資料，確認目標商店正確再繼續。

5. 可以隨時停止 Claude 存取商店嗎？

可以在 Claude 的 Connectors 中解除連接或移除 SHOPLINE；若要調整 AI 後續可使用的範圍，也請回 SHOPLINE 管理員的 API Auth 檢查 MCP 權限。Claude 官方解除連接說明。
