# Max行銷誌文章封面

2026-11-03 依既有文章封面統一 Chrome、NetSuite 教學 01／02、曼谷 Thong Lor 與宮古島咖啡地圖的首圖。

- 使用 **1200 × 675 px（16:9）**。
- 主題相關背景加上紅色遮罩；背景保留輪廓，不影響標題閱讀。
- 白色雙行標題置中：第一行以 `【 主題 】` 呈現，第二行寫文章重點。
- 下方使用珊瑚紅 `Max行銷誌` 字樣，右下角保留方形 `M` 品牌標記。
- 列表、首圖與分享預覽使用相同圖片，並同步尺寸與版本參數。
- 只改首圖時，保留內文圖解與咖啡地圖的互動介面。

可編輯來源位於各篇 `artwork/<slug>/cover.svg`，`cover.html` 可直接預覽。背景使用既有站內素材，Chrome 管理頁背景為向量介面示意。

在 macOS 執行：

```bash
node scripts/prepare-brand-covers.mjs
```

此命令只重建上述五張封面，並更新引用圖片的 HTML 尺寸與內容雜湊版本。如果先執行舊版文章製稿工具，最後再執行此命令，避免舊版首圖覆蓋新樣式。
